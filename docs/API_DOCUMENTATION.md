# BiofilmAI — API Documentation

## Base URL

```
http://localhost:8000
```

The API is served by a FastAPI server running on port 8000.

---

## Authentication

The current version does not require authentication. It is designed for local laboratory use. Authentication will be added in a future version.

---

## Endpoints

### GET /api/health

Health check endpoint.

**Response:**
```json
{
    "status": "ok",
    "version": "0.1.0",
    "demo_mode": true,
    "description": "Research prototype for multimodal prediction of biofilm-associated infection."
}
```

**Status codes:**
- `200 OK` — Server is running

---

### POST /api/analyze

Run a multimodal analysis.

**Request format:** `multipart/form-data`

**Parameters:**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `sampleInfo` | JSON string | Yes | Sample metadata |
| `clinicalData` | JSON string | Yes | Structured clinical information |
| `microscopy` | File (image) | No | Microscopy image (PNG, JPG, TIFF) |
| `spectroscopy` | File (CSV/TXT) | No | Spectroscopy data |
| `genomics` | File (CSV/TXT/FASTA) | No | Genomic sequence data |

**sampleInfo structure:**
```json
{
    "sampleId": "S-01842",
    "studyId": "BF-LONG-2026",
    "sampleType": "Wound swab",
    "collectionDate": "2026-08-18",
    "infectionContext": "Chronic wound",
    "woundOrImplant": "Knee prosthesis",
    "notes": "Research sample"
}
```

**clinicalData structure:**
```json
{
    "infectionContext": "chronic-wound",
    "chronicityDays": 14,
    "implantPresent": true,
    "sampleSite": "Knee (prosthetic)",
    "previousTreatment": "antibiotics",
    "previousCulture": "positive-mixed",
    "additionalNotes": ""
}
```

**Response (Demo Mode):**
```json
{
    "analysisId": "BA-7A1B2C3D4E5F",
    "sampleId": "S-01842",
    "sampleType": "Wound swab",
    "status": "completed",
    "createdAt": "2026-08-18T14:30:00Z",
    "completedAt": "2026-08-18T14:30:01Z",
    "prediction": {
        "biofilmProbability": 0.72,
        "riskCategory": "high"
    },
    "modalities": {
        "microscopy": {"modality": "microscopy", "available": true, "status": "available"},
        "spectroscopy": {"modality": "spectroscopy", "available": true, "status": "available"},
        "genomics": {"modality": "genomics", "available": true, "status": "available"},
        "clinical": {"modality": "clinical", "available": true, "status": "available"}
    },
    "interpretation": {
        "crossAttention": {
            "rows": ["microscopy", "spectroscopy", "genomics", "clinical"],
            "cols": ["microscopy", "spectroscopy", "genomics", "clinical"],
            "values": [[0.38, 0.22, 0.18, 0.22], ...]
        }
    },
    "demoMode": true,
    "modelMode": "demo",
    "message": "DEMO MODE — No clinical prediction is being generated..."
}
```

**Status codes:**
- `200 OK` — Analysis completed
- `400 Bad Request` — Invalid input (missing fields, invalid file types)
- `500 Internal Server Error` — Analysis failed

**Error response structure:**
```json
{
    "error": true,
    "field": "sampleId",
    "message": "Sample ID is required",
    "status_code": 400
}
```

### GET /api/history

List all analyses, newest first.

**Response:**
```json
[
    {
        "analysisId": "BA-7A1B2C3D4E5F",
        "sampleId": "S-01842",
        "sampleType": "Wound swab",
        "createdAt": "2026-08-18T14:30:00Z",
        "modalities": ["microscopy", "spectroscopy", "genomics", "clinical"],
        "prediction": {"biofilmProbability": 0.72, "riskCategory": "high"},
        "status": "completed",
        "demo_mode": true
    }
]
```

**Status codes:**
- `200 OK` — History retrieved
- `500 Internal Server Error` — Fetch failed

---

### GET /api/analysis/{analysis_id}

Retrieve a single analysis by ID.

**Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `analysis_id` | string | The unique analysis ID (e.g., BA-7A1B2C3D4E5F) |

**Response:** Same as `POST /api/analyze` response.

**Status codes:**
- `200 OK` — Analysis found
- `404 Not Found` — Analysis ID not found

---

## Demo ModeBehavior

When `demoMode` is `true`:

1. The prediction is generated by a simple heuritic (modality count + random noise)
2. The `modelMode` is set to `"demo"`(3)
. The `message` field clarifies that no real scientific prediction was made
4. The result stored in histoy with the `demoMode` flag

This is the default and cannot be disablwithout trained model weights.

## API Documentation

The API also provides Swagger UI at http://localhost:8000/docs and ReDoc at http://localhost:8000/redoc.

## CORS

The API accepts requests from `http://localhost:3000` by default. Additional origins can be configured via the `BIOFILM_CORS_ORIGINS` environment variable.
